# 动态障碍物：观测、预测与评测

## 页面展示与评测交通

页面和批量评测统一使用 `fixed / map-corridors-v2`。Urban 的 8 只鸟分布在四条道路的三维走廊，活动高度 10–30 米；校园的 3 只鸟沿固定道路走廊运动。每条走廊采用连续速度的 Bezier 往返，最高速度 3.6 m/s，经过建筑、禁飞区与鸟类包络安全检查。

交通只读取地图几何、鸟类 ID/半径、种子和世界时间，不读取基地、目标、无人机位置或任何参考航线。相同地图和种子下，改变任务、重规划次数、同步步长或对象遍历顺序，交通轨迹保持一致；规划算法的配对比较仍需使用相同任务和观测配置。旧的航线穿越分支已删除。

`run_started`、评测结果与响应回放均记录交通策略、交通版本和观测配置。旧日志没有这些字段时明确标记历史协议，不能声称按当前实现精确复现旧世界。

## 观测边界

浏览器显示完整世界；规划与局部避障只接收 `TrafficObserver` 已交付的观测。默认配置：

- 60 m 范围，10 Hz 采样，0.1 s 固定交付延迟。
- 物理建筑遮挡视线，禁飞区本身不遮挡视线。
- 保留最后一次观测最多 1.5 s，失联期间按观测年龄外推，超时删除；重置任务清空历史。
- 位置噪声、速度噪声和丢包率默认均为零，可通过评测的 `--observation-config-json` 设置。噪声单位分别为 m、m/s，数值表示各轴高斯标准差。

噪声及失联能力是可配置的仿真条件，不代表已实现图像识别或真实雷达。下面的误差校准使用无噪声、无丢包的连续观测；更换观测配置需要重新验证。

## 预测方法

当前使用短时历史驱动的衰减加速度预测：从最近 0.8 s 速度历史估计加速度，按 2 s 时间常数指数衰减，采用已知目标速度上限限制外推；历史不足时使用恒速外推。预测器只接受位置、速度和时间戳，不读取鸟群生成器的未来曲线。观测延迟包含在预测起点与误差余量中。

该模型借鉴 [Singer 模型的加速度衰减假设](https://stonesoup.readthedocs.io/en/latest/stonesoup.models.transition.html#stonesoup.models.transition.linear.Singer)，没有实现完整的 Singer 卡尔曼滤波。[QCNet 官方实现](https://github.com/ZikangZhou/QCNet) 使用道路场景训练数据及深度学习依赖；当前项目缺少对应三维鸟群训练集，因此选择无需新增依赖、可直接验证的运动学预测器。

水平与垂直预测误差分别校准，形成随时间扩大的圆柱形误差范围；避免把水平方向的急转弯误差误当作等大的垂直误差。避障检查相对运动线段到该误差范围的保守距离，继续使用原有三维候选航点、控制器及末端驻留检查。

校准使用两张地图、种子 `2/4/6/8`、每种子 120 s；验证使用独立种子 `9/21/37/53`。分位数是当前模拟器的经验统计，不是安全保证。各轴校准分位数为 99.5%，联合覆盖率必须单独测量，不能直接写成 99.5%。

新走廊的独立验证中，3 s 预测误差 P95：Urban 从恒速基线 1.255 m 降至 0.476 m，校园从 0.603 m 降至 0.221 m；P99 分别为 0.563 / 0.256 m。1/3/6 s 冷启动和暖启动的水平、垂直联合覆盖率均为 100%，仅适用于本次平滑走廊样本，不是现实安全保证。每个时域暖启动城市/校园样本数分别为 7616/2856，相邻预测样本相关，不能按独立试验解释。预测误差表记录校准交通版本，旧交通模型的校准结果不再适用。独立验证数据位于 `outputs/map-corridors/prediction-held-out.json`。

## 风险与日志

位置及障碍物速度沿用 grid、grid/s；半径、距离和净空一律为米。页面和后端共用以下阈值：

- 接触距离 = 障碍物包络半径 + UAV 包络半径 0.4 m，对应页面内圈。
- 安全距离 = 接触距离 + 0.6 m，对应页面外圈。
- 局部避障还考虑预测误差及 0.3 m 规划余量，页面安全圈不代表完整预测误差范围。

当前鸟群半径是演示用包络，不是现实鸟类尺寸。日志区分 `dynamic_separation_violation`（安全间距违规）、`dynamic_envelope_contact`（包络接触）和 `dynamic_near_miss`（完整经过接近区且未违规）。同一遭遇发生违规时不重复算作近失；接触可与安全间距违规同时成立。事件记录开始/结束时间、持续时间、全过程最小净空及相对速度；JSONL 在开始和结束时分别记录，关闭运行时保留当前事件汇总。接触指标不等于网格模型的真实物理碰撞。

风险卡和鸟圈颜色显示当前距离风险；对象数据另保留明确标为 `relative_constant_velocity` 的相对速度最近接近指标，局部避障使用历史预测轨迹，两者含义不同。

## 避障过程展示

`flight.avoidance.visualization` 只面向页面，包含原控制指令和最终避障指令各自的控制器 rollout、相关鸟类 ID 及本次避障状态。灰黄虚线为原控制预测、橙实线为避让预测、蓝虚线为正在执行的航段；与 UAV 使用同一延迟仿真时钟，结束后保留 3 秒。

`predicted_clearance_m` 包含预测误差余量；`episode.min_separation_clearance_m` 则是关联鸟群在本次避障期间的实测扫掠安全净空，二者不混用，未测得时为 null。日志记录 `avoidance_started / avoidance_cleared / avoidance_interrupted`，恢复航行不自动等同于安全成功，仍需检查接触及间距违规指标；临时航点调整次数也不等于避障事件次数。展示及真值测量不传给 DeepSeek 或本地规划器。

## 复核

```bash
python scripts/verify_traffic_prediction.py --output outputs/traffic-prediction/held-out-final.json
python scripts/run_benchmark.py --scenario urban_crossing --seed 7 --seed 11 --traffic-policy fixed --max-seconds 240 --output fixed.json
python scripts/verify_traffic_upgrade.py --output outputs/traffic-upgrade
```

第一条只验证预测器，不给预测器访问评分用的未来真值。第二条进行本地 Mock 批量评测，第三条在隔离服务中验证普通任务的交通显示与真实 WebGL 画面；校园的语义解释和实飞控制应分别验证，离线语义响应桩不等于真实 DeepSeek API 验收。已移除的横穿演示使用独立的零时刻规划协议，通用响应回放仍明确拒绝其历史日志，避免错误复现。
