# 北航杭州国际校园模型

本模型用于单无人机自然语言任务仿真，替换原来的通用园区地图；场景 ID 仍为 `semantic_campus`，Urban Crossing 保持独立。

## 建模依据

- 用户提供的南侧航拍照片：校门广场、田径场、体育馆、中央大屋顶及周边楼群的体量、材质和视角。
- 用户提供的校园导览图：北向、C1–C9、R1–R3、L1–L6、D1–D14、A1–A5、运动设施、水系与出入口的相对位置。
- [HENN 官方项目资料](https://www.henn.com/en/project/hangzhou-international-innovation-institute)：南北学术轴、东西景观轴，以及沿南北方向下凹的轻薄屋顶、矩形天窗和中央透光条缝。

落位以用户导览图为主，建筑外观以航拍和实景为主。图上的分区颜色不作为外墙颜色。未将参考照片下载或复制为模型贴图，材质由本地代码生成。

## 空间与简化

96 × 96 的仿真网格沿用每格 3 米、每高度单位 5 米的坐标体系，北向为 y 减小的方向。校园按图像比例缩尺，建筑高度、楼层、窗格和景观细部均为近似；这些坐标和页面距离不等同于真实校园测绘数据。

中央组团按南北顺序布置 C1/C2、C3/C4、C5、C6/C7、C8/C9；科研楼保留多翼庭院，东侧分布南北生活区，西南侧为田径场及体育馆，东南侧为实验组团。建筑以白灰框架、玻璃幕墙和局部暖色窗带呈现。

主楼墙面位于角柱、楼层边条和门框内侧 3 厘米，避免重合表面随镜头移动产生闪烁。科研楼中央楼翼与侧翼的重叠体积只绘制一次；装饰外边界及共享碰撞占地保持原布局。

## 飞行与任务

共享布局在 `uav_llm_demo/campus_layout.py` 中定义，前端几何与后台障碍物均由此生成。巡检点设在建筑外部净空位置；默认作业高度随地点变化，用户指定限高后仍需通过可达性检查。南广场、南北生活区可作为用户指定的避让区域，不将它们声明为真实校园禁飞区。

大屋顶采用从地面到最高点的保守碰撞柱体，避免无人机穿越悬挑结构；当前不支持屋檐下或室内飞行。中央透光条缝与玻璃天窗同样计入屋顶障碍。装饰植被低于最低巡航高度，起降区保持净空。

DeepSeek 负责理解地点、顺序、条件和约束，本地规划器执行三维航路。图书馆与实验一号楼提供模拟热观测，其异常结果只是仿真任务数据。其他技能和任务完成判定沿用现有执行逻辑。

## 验证

地图测试检查布局一致性、观测点安全、各地点之间的可达性和命名避让区域；服务测试检查默认高度、10 米限高、条件分支及完整返航落地。浏览器验证检查总览、跟随视角、场景切换、控制台错误和可见模型，并追踪移动镜头下的角柱和楼层边条像素，检查墙面遮盖闪烁；报告和截图保存在 `outputs/campus-scene/`。
